QodeForge 27.0.0 — بسته تجمیعی اصلاحات و ویرایشگر تمام‌صفحه واقعی (در حال توسعه)

این ZIP شامل اصلاحات قبلی ده ابزار، بازطراحی ویرایشگر کد، اصلاح کامل UI و تمام‌صفحه واقعی و یکپارچه‌سازی تاریخچه اشتباه نسخه است.
نیازی به نصب ZIP قدیمی همین نسخه نیست؛ این بسته جایگزین کامل آن است.

روش نصب:
۱. از پروژه نسخه پشتیبان بگیرید.
۲. محتویات ZIP را مستقیماً در ROOT پروژه استخراج کنید و فایل‌های هم‌نام را جایگزین کنید.
۳. برای پاک‌سازی دو ابزار حذف‌شده، اسکریپت را از ROOT اجرا کنید:
   لینوکس/مک: sh apply-qodeforge-27.0.0.sh
   ویندوز: powershell -ExecutionPolicy Bypass -File .\apply-qodeforge-27.0.0.ps1
۴. بیلد کامل پروژه اصلی و آزمون‌های مرورگر را انجام دهید.

ویرایشگر کد: مسیر ابزار /tools/code-editor
حالت تمام‌صفحه: دکمه گسترش، با Fullscreen API واقعی مرورگر؛ خروج با Esc یا دکمه بازگشت.
در مرورگرهای ناسازگار یا بدون مجوز Fullscreen، حالت تمام‌صفحه حقیقی نمایش داده نمی‌شود و پیام خطا نشان داده خواهد شد.
Explorer: عرض قابل تغییر با کشیدن جداکننده، نمایش جمع‌شده پوشه‌های تودرتو، میانبرهای جستجو و تب‌ها.
Ctrl+P: دسترسی سریع به فایل | Ctrl+Shift+F: جستجوی پروژه | Ctrl+B: Explorer
Ctrl+S: ذخیره | Ctrl+W: بستن تب | Ctrl+F: جستجوی داخل کد

نکات:
- نسخه 27.0.0 هنوز Development است، نه انتشار عمومی تأییدشده.
- نسخه مستقلِ اشتباه حذف و تمام یادداشت‌هایش زیر 27.0.0 تجمیع شدند.
- ذخیره مجازی مرورگر با ذخیره واقعی روی دیسک فرق دارد. ویرایشگر در صورت تغییرات دیسکی ذخیره‌نشده هشدار می‌دهد.
- ویرایشگر محیط کد است، نه ترمینال/اجراکننده زبان‌ها/Debugger کامل.
- دسترسی مستقیم به پوشه به File System Access API و مجوز کاربر نیاز دارد.
- ورودی فقط src بود: package.json، lockfile، tsconfig.json و public در اختیار نبودند.
- لاگ جزئی و نتایج آزمون: CHANGELOG-27.0.0-TECHNICAL.fa.md
- فایل‌های تغییرکرده: PATCH-FILES.txt؛ هش‌ها: PATCH-SHA256.txt

اصلاح آیکن‌های خارج از مرکز: در ویرایشگر کد، دکمه‌های آیکنی Explorer، تب‌ها، Toolbar و Activity Bar به مرکز بازگردانده شده‌اند.
تمام تغییرات در همان نسخه 27.0.0 و فایل‌های changelog فارسی و انگلیسی ثبت شده‌اند.
